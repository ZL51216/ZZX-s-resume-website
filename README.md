静态页面，无框架、无构建步骤、无 CDN 依赖，离线也能正常打开。

```

└── README.md
```

## 交互

- **明暗主题**：导航栏右侧按钮一键切换，写入 `localStorage` 记忆；首次访问跟随系统 `prefers-color-scheme`。`<head>` 内联脚本先套用主题，避免刷新闪白。
- **悬停动效**：证件照放大 1.06 倍，经历卡片、技能卡、联系卡上浮 3px 并加深阴影。
- **滚动渐显**：`.reveal` 元素由 `IntersectionObserver` 触发，200ms 后兜底显示首屏内容。
- **导航高亮**：滚动时自动标记当前区块。
- **移动端（≤768px）**：导航折叠为汉堡菜单，卡片改为单列。

## 发布

仓库根目录需直接包含 `index.html` 及 `assets/`、`script.js`。若部署到 `https://<用户名>.github.io` 用户站，
请把本目录内容放到仓库根，而不是再套一层同名文件夹，否则访问会 404。

替换简历或证件照时，直接覆盖 `assets/` 下同名文件即可，无需改代码。
